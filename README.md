# Prasanthi Farm House - Official Static Website

A high-performance, modern static website for **Prasanthi Farm House**, an open resort on the banks of Ashtamudi Lake in Kollam, Kerala. 

Features **2 exclusive lakefront rooms** and an expansive **open-air waterfront celebration lawn** for intimate weddings, birthdays, family get-togethers, and serene backwater escapes.

---

## 🌟 Key Features

1. **Brand Identity & Authentic Visuals:**
   - Real photos (`assets/images/img_1.webp` to `img_6.webp`) capturing the traditional Kerala cottage, clay tiled roofs, sit-out verandah, stone courtyard, palm trees, and golden Ashtamudi lake sunset.
   - Built-in video player & modal playing `assets/videos/prasanthi_vid_two.mp4`.
2. **Dual Showcase:**
   - **Boutique Stays:** Highlighting Room 1 (Heritage Verandah Suite), Room 2 (Palm Courtyard Room), and whole property buyout.
   - **Lakeside Celebrations:** Waterfront lawn, fairy festoon lights, wedding mandap & birthday party setups.
3. **Direct WhatsApp Booking Engine:**
   - Customized inquiry form that dynamically builds a formatted WhatsApp message to `+91 94470 72207` (with secondary line `+91 62824 26120`).
4. **Interactive Gallery & Lightbox:**
   - Filter by Lake & Sunset, The Cottage, and Lawn & Celebrations.
   - Lightbox modal with full keyboard navigation (Escape, Left, Right).
5. **Location & Directions:**
   - Direct link to official Google Maps location (`https://maps.app.goo.gl/DRsJ3ADcTVmQUzbP9?g_st=ac`).
   - Distance points from Kollam Junction (12 km), TRV Airport (75 km), and Munroe Island.
6. **Instagram Integration:**
   - Direct link to [@prasanthi_farmhouse](https://www.instagram.com/prasanthi_farmhouse/).

## 🚀 How to Run Locally

You can preview the website instantly by opening `index.html` in any web browser, or starting a local lightweight HTTP server:

```powershell
# Using Python
python -m http.server 8000

# Then open in browser:
http://localhost:8000
```
